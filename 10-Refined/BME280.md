# BME280

A combined temperature, humidity, and barometric pressure sensor in a single low-cost,
low-power package — the chosen sensor for the [[Backyard Weather Station]].

## Key points

- Three measurements (temperature, humidity, pressure) on one breakout board.
- Speaks **I2C** (simple two-wire) or SPI; default I2C address 0x76 or 0x77.
- Accuracy ≈ ±1 °C and a few % RH.
- **Self-heating caveat:** mounted next to a warm MCU/radio it can read 1–2 °C high. Mount it
  away from heat sources or read infrequently. (Noted independently in both sources below.)
- Pairs naturally with the [[ESP32]] over I2C.
